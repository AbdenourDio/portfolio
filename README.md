# Personal Portfolio Website 🚀

Welcome to the repository for my personal portfolio website. This site serves as a clean, centralized showcase for my background as a Computer Science student and my engineering focus on backend development, automation, and API integrations.

🔗 **Live Link:** [https://AbdenourDio.github.io/portfolio/](https://AbdenourDio.github.io/portfolio/)

---

## 🛠️ Built With

This portfolio was built from scratch without bloated frameworks to ensure maximum performance, clean semantics, and responsive layout scaling:

* **HTML5** - Semantic structure and content organization.
* **Modern CSS3** - Custom properties (CSS variables), CSS Grid architecture, Flexbox alignment, and fluid keyframe animations (for interactive visual cues).
* **Design Aesthetic:** Deep dark mode optimizations inspired by the classic Dracula developer theme color palette.

The primary focus of this portfolio is highlighting my **Sales Automation & Shipment Tracking System**—a multi-month custom application designed to interface directly with external delivery company REST APIs to eliminate manual workflows for e-commerce sellers.
