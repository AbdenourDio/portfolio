Spaceship War Desktop Game

Desktop App

A local 2-player combat arcade game built completely from scratch using Python and the community-driven pygame-ce library. I had a lot of fun making this project while learning the mechanics behind running dynamic gameplay systems.

🛡️

Handling Collisions

Learned how to map running hitbox coordinates (`pygame.Rect`) to flag instantly when bullet arrays strike moving target vectors.
⏱️

Frame Rate Control

Gained experience tying updates to an explicit clock tick loop (60 FPS) to guarantee smooth sprite motion across different machine setups.
🚀

Vector Math & Bullets

Mastered dynamic object handling by updating object positioning arrays on every loop cycle, and safely scrubbing off-screen data arrays out of memory.
🎮

Same-Keyboard PVP

Player 1 moves via Q Z S D and shoots with Left CTRL; Player 2 handles the Arrow Keys and Right CTRL.
